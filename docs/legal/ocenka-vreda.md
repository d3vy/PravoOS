# Оценка вреда, который может быть причинён субъектам персональных данных

Внутренний документ. Требование ч. 5 ст. 18.1 152-ФЗ; форма и критерии — Приказ Роскомнадзора
от 27.10.2022 № 178 «Об утверждении Требований к оценке вреда, который может быть причинён
субъектам персональных данных в случае нарушения Федерального закона „О персональных данных“».

## 1. Порядок оценки

1.1. Вред оценивается отдельно по каждой категории субъектов и каждому виду нарушения:
неправомерная передача (предоставление, распространение, доступ), уничтожение, изменение,
блокирование персональных данных.

1.2. Применяется трёхуровневая шкала Приказа № 178: **высокая**, **средняя**, **низкая** степень
вреда. Степень определяется по последствиям для субъекта, а не по ущербу для Оператора.

1.3. Оценка пересматривается не реже одного раза в год, а также при изменении состава
обрабатываемых данных, целей обработки или перечня привлекаемых лиц.

## 2. Категории субъектов

| № | Категория | Ориентировочное количество | Роль Оператора |
|---|---|---|---|
| 1 | Пользователи сервиса (юристы, сотрудники юридических фирм, администраторы) | до 10 000 | Оператор |
| 2 | Кандидаты в пользователи (поданные заявки) | до 20 000 | Оператор |
| 3 | Пользователи клиентского портала (доверители, приглашённые юристом) | до 50 000 | Оператор в части учётной записи |
| 4 | Лица, сведения о которых внесены пользователем (доверители, контрагенты, участники дел) | не ограничено, определяется пользователями | Обработчик по поручению |

## 3. Оценка вреда

### 3.1. Пользователи сервиса

| Нарушение | Последствия для субъекта | Степень |
|---|---|---|
| Неправомерный доступ к ФИО, e-mail, телефону | Нежелательные обращения, фишинг, подбор пароля к другим сервисам | **Средняя** |
| Неправомерный доступ к учётной записи (компрометация сессии) | Доступ к материалам дел доверителей → нарушение адвокатской и профессиональной тайны, репутационный и имущественный ущерб | **Высокая** |
| Уничтожение данных учётной записи | Потеря доступа к рабочим материалам, срыв процессуальных сроков | **Высокая** |
| Изменение данных (подмена реквизитов, платёжных сведений) | Имущественный ущерб, направление платежей третьему лицу | **Высокая** |
| Блокирование данных | Временная невозможность работы | **Низкая** |

### 3.2. Кандидаты в пользователи (заявки)

| Нарушение | Последствия для субъекта | Степень |
|---|---|---|
| Неправомерный доступ к ФИО, e-mail, телефону, специализации | Нежелательные обращения, раскрытие факта поиска инструментов практики | **Средняя** |
| Уничтожение | Повторная подача заявки | **Низкая** |
| Изменение | Ошибочный отказ либо предоставление доступа не тому лицу | **Средняя** |

### 3.3. Пользователи клиентского портала

| Нарушение | Последствия для субъекта | Степень |
|---|---|---|
| Неправомерный доступ к учётной записи | Раскрытие сведений о судебном деле субъекта, о его правовой позиции и о факте обращения к юристу | **Высокая** |
| Уничтожение | Потеря доступа к материалам и счетам | **Средняя** |
| Изменение | Введение в заблуждение относительно хода дела и сумм к оплате | **Высокая** |

### 3.4. Лица, сведения о которых внесены пользователем

| Нарушение | Последствия для субъекта | Степень |
|---|---|---|
| Неправомерный доступ к материалам дела | Раскрытие сведений, составляющих охраняемую законом тайну (адвокатскую, коммерческую, семейную); возможны сведения о состоянии здоровья, судимости, имущественном положении, содержащиеся в материалах | **Высокая** |
| Уничтожение | Утрата доказательственной базы у оператора-пользователя | **Высокая** |
| Изменение | Искажение сведений о правовой позиции и обстоятельствах дела | **Высокая** |
| Блокирование | Задержка оказания юридической помощи | **Средняя** |

## 4. Итоговая оценка

4.1. **Максимальная степень возможного вреда — высокая.** Она обусловлена не составом полей
учётной записи, а содержанием материалов дел: произвольные документы, размещаемые пользователями,
могут содержать любые категории сведений, включая специальные (ст. 10 152-ФЗ).

4.2. Высокая степень вреда сама по себе уровень защищённости не задаёт: он определяется по
ПП РФ № 1119 через категорию данных, тип актуальных угроз и число субъектов. Расчёт и обоснование —
[model-ugroz.md](model-ugroz.md), раздел 4. Но именно высокая степень вреда обязывает не
ограничиваться минимумом требований выбранного уровня.

4.3. Отдельно учтено: неправомерная передача сведений о факте обращения лица за юридической
помощью сама по себе причиняет вред, независимо от содержания материалов.

## 5. Меры, снижающие вероятность наступления вреда

| Мера | Что снижает |
|---|---|
| Шифрование ФИО, телефона, e-mail, ИНН и заметок клиентов в базе (AES-256-GCM) | Ценность дампа базы при неправомерном доступе |
| Шифрование файлов документов при хранении | Ценность доступа к файловому хранилищу |
| Изоляция данных по владельцу и организации на уровне каждого запроса | Горизонтальное разглашение между пользователями |
| Раздельные роли `LAWYER` / `ADMIN` / `CLIENT`, запрет по умолчанию для неизвестных путей | Расширение доступа при ошибке конфигурации |
| Обезличивание текста перед передачей внешней модели | Вред от трансграничной передачи |
| Журналы доступа, уведомление о входе с нового устройства, управление сессиями | Время необнаруженного доступа |
| Антивирусная проверка загружаемых файлов | Компрометация инфраструктуры через загрузку |
| Резервное копирование с проверяемым восстановлением | Вред от уничтожения данных |
| Уведомление об инциденте в течение 24 часов | Время, в течение которого субъект не может защититься |
