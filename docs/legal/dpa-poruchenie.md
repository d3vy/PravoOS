# Поручение на обработку персональных данных

Раздел оферты (договора) между {{ОПЕРАТОР}} и Пользователем. Оформляется во исполнение ч. 3 ст. 6
Федерального закона от 27.07.2006 № 152-ФЗ.

**Оператор персональных данных по настоящему разделу — Пользователь.**
**Лицо, осуществляющее обработку по поручению (далее — Исполнитель), — {{ОПЕРАТОР}}.**

**Редакция:** {{ДАТА_РЕДАКЦИИ}} · **Версия:** 1.0

## 1. Предмет поручения

1.1. Пользователь поручает Исполнителю обработку персональных данных третьих лиц, которые
Пользователь самостоятельно вносит в сервис PravoOS или которые попадают в сервис из подключённых
Пользователем источников (почтовый ящик, карточки клиентов, материалы дел, загруженные документы).

1.2. Исполнитель обрабатывает такие данные исключительно в целях функционирования сервиса и в
объёме, необходимом для оказания услуг по договору. Собственных целей обработки Исполнитель не
определяет и в собственных интересах эти данные не использует.

1.3. Согласие субъекта на обработку данных, вносимых в сервис, получает Пользователь. Исполнитель
не вступает в отношения с такими субъектами и не проверяет наличие согласия. Сервис предоставляет
Пользователю инструмент фиксации согласий (карточка клиента → «Согласие на обработку ПДн»,
таблица `client_consents`).

## 2. Перечень действий и категории данных

2.1. Разрешённые действия: сбор, запись, систематизация, накопление, хранение, уточнение
(обновление, изменение), извлечение, использование, блокирование, удаление, уничтожение;
обезличивание — в объёме, описанном в п. 4.4.

2.2. Категории субъектов: доверители Пользователя, их представители, контрагенты, участники дел,
иные лица, сведения о которых содержатся в материалах, размещённых Пользователем.

2.3. Категории данных: фамилия, имя, отчество; контактные данные; ИНН; реквизиты организаций;
содержание документов и переписки по делу. Конкретный состав определяет Пользователь. Перечень мест
хранения — [perechen-pdn-i-sroki.md](perechen-pdn-i-sroki.md), раздел 2.

2.4. Пользователь **не вправе** размещать в сервисе биометрические персональные данные (ст. 11
152-ФЗ). Специальные категории (ст. 10) могут содержаться в материалах дел; Пользователь
подтверждает, что имеет законное основание их обработки, и несёт за это ответственность.

## 3. Обязанности Исполнителя

3.1. Обрабатывать данные только по документированному поручению Пользователя — то есть в объёме
функций сервиса, инициируемых действиями Пользователя.

3.2. Соблюдать конфиденциальность и требования к безопасности, установленные ст. 19 152-ФЗ и
ПП РФ № 1119. Применяемые меры перечислены в разделе 5.

3.3. Обеспечивать локализацию: базы данных, содержащие персональные данные граждан Российской
Федерации, находятся на территории Российской Федерации (ч. 5 ст. 18 152-ФЗ). Размещение —
{{ХОСТИНГ}}.

3.4. Не передавать данные третьим лицам, кроме привлечённых субподрядчиков, перечисленных в
[reestr-obrabotchikov.md](reestr-obrabotchikov.md), и кроме случаев, прямо предусмотренных законом.

3.5. Уведомлять Пользователя о фактах неправомерной передачи (предоставления, распространения,
доступа) персональных данных в срок, не превышающий 24 часов с момента выявления. Порядок —
[reglament-utechki.md](reglament-utechki.md).

3.6. Содействовать Пользователю в исполнении обращений субъектов (ст. 14, 20, 21 152-ФЗ):
предоставлять выгрузку, исправлять и удалять данные по запросу Пользователя средствами интерфейса
сервиса.

3.7. По прекращении договора — прекратить обработку и уничтожить данные в срок, указанный в п. 6.

## 4. Субподрядчики и трансграничная передача

4.1. Исполнитель вправе привлекать субподрядчиков для обработки. Актуальный перечень —
[reestr-obrabotchikov.md](reestr-obrabotchikov.md), он публикуется по адресу
{{ДОМЕН}}/legal/privacy и является частью настоящего поручения.

4.2. Исполнитель отвечает перед Пользователем за действия субподрядчиков как за свои собственные.

4.3. Об изменении перечня субподрядчиков Исполнитель уведомляет Пользователя не менее чем за 15
календарных дней. Несогласие Пользователя даёт ему право расторгнуть договор без штрафных санкций.

4.4. Функции, использующие внешнюю языковую модель, передают текст **после автоматического
обезличивания** и **только при наличии отдельного согласия** субъекта на трансграничную передачу
(ч. 4 ст. 12 152-ФЗ). Условия и риски — [soglasie-transgranichnaya-peredacha.md](soglasie-transgranichnaya-peredacha.md).
При отсутствии согласия соответствующие функции для Пользователя недоступны, обработка остальных
данных продолжается в прежнем объёме.

## 5. Меры безопасности

| Требование ст. 19 152-ФЗ | Реализация в PravoOS |
|---|---|
| Разграничение доступа | Аутентификация по JWT, роли `LAWYER` / `ADMIN` / `CLIENT`, изоляция по владельцу и организации на уровне запросов |
| Защита при хранении | AES-256-GCM для ФИО, телефона, e-mail, ИНН и заметок клиентов; шифрование файлов документов |
| Защита при передаче | TLS для всех внешних соединений, mTLS/секрет для внутренних вызовов между сервисами |
| Обнаружение фактов НСД | Журналы доступа, журнал сессий и устройств, уведомление о входе с нового устройства |
| Антивирусный контроль | Проверка загружаемых файлов антивирусом до сохранения, контроль активного содержимого |
| Восстановление | Резервное копирование баз данных, проверяемое восстановление |
| Оценка эффективности мер | Внутренний контроль не реже одного раза в год, [model-ugroz.md](model-ugroz.md) |

## 6. Сроки хранения и уничтожение

6.1. Данные, размещённые Пользователем, хранятся всё время действия договора.

6.2. Удаление Пользователем объекта в интерфейсе (клиента, дела, документа) влечёт удаление
соответствующих данных, включая производные (векторные представления фрагментов документов).

6.3. При прекращении договора данные Пользователя уничтожаются в течение 30 календарных дней. В
течение этого срока Пользователь вправе получить выгрузку. Факт уничтожения фиксируется актом по
форме [akt-unichtozheniya.md](akt-unichtozheniya.md).

6.4. Резервные копии, содержащие уничтоженные данные, выходят из ротации не позднее 90 дней;
из резервных копий данные не восстанавливаются, кроме случая аварийного восстановления системы
целиком.

## 7. Ответственность

7.1. Пользователь отвечает за правомерность обработки: наличие согласий, соблюдение целей и сроков,
законность самого факта размещения данных в сервисе.

7.2. Исполнитель отвечает перед Пользователем за нарушение настоящего поручения. Перед субъектом
персональных данных ответственность несёт Пользователь как оператор (ч. 5 ст. 6 152-ФЗ).

7.3. Настоящий раздел действует с момента акцепта оферты и до прекращения обработки по п. 6.3.
