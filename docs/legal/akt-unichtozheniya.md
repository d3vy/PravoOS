# Акт об уничтожении персональных данных (форма)

Внутренний документ. Основание: ч. 5 ст. 21 152-ФЗ; требования к подтверждению уничтожения —
Приказ Роскомнадзора от 28.10.2022 № 179 «Об утверждении требований к подтверждению уничтожения
персональных данных».

Акт составляется при каждом уничтожении: по обращению субъекта, по достижении цели обработки, по
истечении срока хранения, при прекращении договора с пользователем.

**Если обработка ведётся с использованием средств автоматизации, акт составляется вместе с
выгрузкой из журнала регистрации событий в информационной системе** (п. 2 Требований). Один
документ без другого подтверждением уничтожения не является.

содержащая (п. 2 Требований Приказа № 179):

- сведения о субъектах, чьи данные уничтожены (идентификаторы без раскрытия самих данных);
- перечень категорий уничтоженных данных;
- наименование информационной системы;
- сведения о лице, инициировавшем уничтожение.

## Порядок хранения актов

Акты хранятся **3 года** с даты составления вместе с приложенными выгрузками из журнала
(п. 4 Требований Приказа № 179) и предъявляются по запросу Роскомнадзора или субъекта.
